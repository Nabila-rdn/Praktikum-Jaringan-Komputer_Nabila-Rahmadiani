# Judul 1 – Basic Network Configuration

## Deskripsi
Praktikum jaringan komputer pada judul 1 membahas konfigurasi dasar jaringan komputer menggunakan simulasi Cisco Packet Tracer. Prosesnya meliputi pembangunan topologi jaringan (PC, Switch, dan Router), pengaturan IP Address pada end device, konfigurasi dasar pada Switch dan Router, serta pengujian konektivitas jaringan.
